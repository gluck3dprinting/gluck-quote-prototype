# GLUCK 실시간 견적 페이지 (프로토타입 v17)

산업용 SLA 3D프린팅 양산 의사결정을 돕는 **실시간 견적 페이지 프로토타입**입니다.
글룩이 단순 출력 업체가 아닌 **디지털 파운드리**라는 본질을 페이지에 담는 것을 목표로 합니다.

> ⚠️ 내부 테스트용 프로토타입입니다. 실제 견적은 [glucklab.com](https://glucklab.com/estimate/real-time_estimate.html?lang=ko)에서 확인해주세요.

## 주요 기능

### 멀티 파트 프로젝트 견적
- 여러 STL/OBJ 파일을 한 프로젝트로 동시 관리
- 파트별 소재·수량 개별 설정
- 프로젝트 전체 견적 합산 + 예상 납기

### 3D 뷰어
- 사이즈 박스 (BBox) — 모델 크기 즉시 인지
- 빌드 플레이트 그리드 (1 cell ≈ 10mm)
- **GLUCK 워드마크 스케일 레퍼런스** (약 40×12mm) — 빌드 플레이트 위 입체 로고
- 자동 회전 + 일반/투명 모드
- v1 스타일 부드러운 보라톤 조명

### DfM 검사 (글룩 핵심 2항목)
- **Open mesh / Hole** — 진짜 boundary edge만 검출 (false positive 방지)
- **Thin wall** — 0.6mm 미만 영역 감지
- 빨간 반투명 면으로 시각화

### 영업·CRM 통합
- 페이지 하단 **CRM 데이터 미리보기** — 영업팀 인계용 JSON 자동 생성
- 수량 2개+ 부터 양산 안내, 100개+ 부터 상담 권장 메시지

## 테스트 방법

1. 위 라이브 데모 링크 접속
2. STL/OBJ 파일을 드래그앤드롭 (또는 클릭 업로드)
3. 자동 분석 완료 후 옵션 선택 → **견적 계산하기**
4. 여러 파일 동시 업로드해서 멀티 파트 견적도 테스트
5. 페이지 하단 **CRM 데이터 미리보기** 펼쳐서 JSON 구조 확인

### 지원 파일 형식
- **권장**: STL, OBJ
- **부분 지원**: STEP, STP, 3MF, ZIP
- **최대 크기**: 파일당 100MB

### 테스트 STL 파일이 없다면

다음에서 무료로 다운로드 가능합니다:
- [Thingiverse](https://www.thingiverse.com/)
- [GrabCAD Library](https://grabcad.com/library)
- [Printables](https://www.printables.com/)

## 피드백 받고 싶은 부분

- [ ] 흐름이 자연스러운가 (업로드 → 분석 → 옵션 → 견적)
- [ ] 부족한 정보가 있는가
- [ ] 실제 영업·CRM에서 사용 가능한 데이터 구조인가
- [ ] 빌드 플레이트의 GLUCK 로고가 스케일 비교에 도움되는가
- [ ] 빨간색 Hole 표시가 정확한가 (정상 메시에 false positive 없는지)
- [ ] 투명 모드에서 내부 구조가 잘 보이는가
- [ ] 모바일·태블릿에서도 사용 가능한가
